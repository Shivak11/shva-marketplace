# Search Playbook

Every claim about a book must come from a live search in the current session. Use whichever web search tool exists (WebSearch, web_search, perplexity_search). Do not rely on memory for publication year, author credentials, chapter structure, or reception.

## Discovery sequence (minimum four searches)

1. Broad: topic + "framework" + "organizational" or the domain noun
2. Author-specific: known authors in the space + recent titles
3. Historical precedent: topic + "1990s" or the foundational framework name; who proposed this before the current hype?
4. Critical: topic or title + "criticism", "review", "post-mortem", "revisited"
5. Optional: academic version of the same idea (journal article, working paper)

Query construction
- Specific terminology, not buzzwords
- Add timeframes when hunting foundational work
- Search for academic sources alongside trade books
- Prefer original sources (publisher pages, author sites, university pages, SSRN, ACM) over aggregator listicles

## Verdict sequence (one book)

1. Title + author: confirm year, publisher, page count, structure
2. Author name alone: what else have they written, do they run a keynote business, is the blurb language inspirational
3. Title + "review" from technical or academic readers, and three-star Amazon reviews
4. Title + the concept it is best known for + "original" or "based on": find the academic source it may be repackaging
5. If under six months old: search for early critical takes; verdict stays provisional

## Hype-cycle timing

- 0–6 months: high risk of riding a trend. Sample first. Offer "verdict pending reviews in three months".
- 1–2 years: reviews settled, staying power assessable. Safe to evaluate.
- 5+ years: classic or dated? Check for an updated edition and whether the framework is still cited.

## Special cases

Hyped but suspect
1. Find three-star reviews (critical but not trolling)
2. Find reviews from technical readers on Goodreads
3. Check author's previous work for Sinek-adjacency
4. Name specific chapters to sample
5. Offer the "wait three months" option

Historical precedent exists
1. Name the "new" concept
2. Search 1970s–1990s management literature for the same idea
3. Identify the original framework
4. Explain why it failed then and what changed now (usually technology)
5. Recommend the retrospective, not the original

Academic foundation, no single book
1. Point to the original papers for grounding
2. Find one accessible practitioner translation if it exists
3. Suggest an article search rather than a book

User already teaches the topic
1. Open with the remedial warning
2. List only what is new
3. Recommend skipping if the book only repackages what he teaches

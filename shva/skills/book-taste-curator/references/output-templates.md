# Output Templates

Plain text, no italics, no closing summary. Lead with the reframe.

## Discovery

Open with one paragraph: what the underlying question is, and what the topic actually maps to (including any historical precedent).

STRONG RECOMMEND (maximum three)

**[Title]**, Author(s), Year, Publisher
One-sentence framework summary.

Why it fits:
- Framework it hands over (name it, with one example from the book)
- Structural characteristic (modular, illustrated, numbered, dense)
- Content match
- Voice match
- Teaching deliverable: what MDP session or Rehearsal feature this becomes

Your type: analogy to a book from the library (e.g., "Chip Wars for X")

Warning: specific caveat with chapter or page numbers to sample, if any

MAYBE (sample first)

**[Title]**, Author(s)
Which yellow flags. Which chapters or pages to sample and what to look for. What would convert this to STRONG.

SKIP

**[Title]**: one line on the red flag or on which better book already covers it.

Reading order: sequence with reasoning.

If you read only one: pick, and why over the alternative.

Historical context: when it was written, what problem it was solving.

What the critics say: one or two substantive objections from Tier 1 or Tier 2 sources.

## Comparison (multiple books, same topic)

If you want [X]: read [Book A]
If you want [Y]: read [Book B]
If you read only one: [pick, reasoning]
Skip entirely: [titles, one line each]

## Verdict (single book)

Verdict line first: STRONG / MAYBE / SKIP.

Then in order:
1. The framework it hands over, named
2. What is new versus repackaged (and what it repackages, if anything)
3. The remedial risk, if he already teaches this
4. The better book, if one exists
5. Sampling instructions if MAYBE: chapters, pages, what to look for
6. What the three-star reviews say

## Extraction (prompt vocabulary)

Open with one line: the book's core operation as a verb.

Structural commands (what to build)
- [Command phrased as a prompt instruction]: source concept in the book, and the constraint it imposes
- ...

Style commands (how to write it)
- [Command phrased as a prompt instruction]: source concept, and what it bans
- ...

Banned by the author (use as negative instructions)
- ...

Layered example
One combined instruction that stacks a structural command on a style command, ready to paste into a system prompt.

Product implication
One paragraph: the Rehearsal or MDP feature this suggests. If the obvious workflow is forward-sequential, name the inverted version.

Question to close: which of these moves is being applied, and where.

## Rebuttal (confirmation line)

One line: "Added [Title] to [section] in library.md: [reason]." Plus, if a pattern was added: "Taste profile updated: [rule], because it also explains [two existing entries]."

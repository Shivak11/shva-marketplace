# Design Taste — source it, don't invent it

Before laying out, pull real references with **Mobbin** (`mcp__mobbin__search_screens`; platform `web`
for forms, `ios` for reflective / journaling prompts). Cite the screen URLs back to Shiva.

## The standing patterns (validated, reuse these)

These transfer directly to a print worksheet and are already baked into
`assets/worksheet-template.html`:

- **Per-field, self-contained (Peerspace / Upwork onboarding forms):** a real question → a short "how
  to think" line → the input → a faint **"Example: …"** right there. This is the spine of every field.
- **Fill-in-the-blank prompts (ABY Journal / 5 Minute Journal / Calm):** sentences with blanks on the
  line, a quiet subtitle under each prompt, and the tip shown *at the moment of writing*. This is where
  the "Be Mindful! in context" and the fill-in-sentence patterns come from.
- **General taste:** large readable question labels, generous whitespace, a soft warm background, one
  accent colour, examples in faint italic, plenty of room to write.

## Search queries that work

- web: `form input field with a faint example placeholder inside and a short helper hint below the field`
- ios: `guided journaling reflection prompt with a question, a text answer area, and a small tip on how to think`
- web: `multi-step worksheet with a sidebar of tips next to the main form` (only if you want a margin layout)

## When to search again

Only re-search Mobbin if the topic needs an interaction the template does not already cover (a ranking,
a matrix the 2×2 doesn't fit, a timeline, a slider-style scale). Otherwise reuse the template and spend
the effort on content. Always show Shiva the Mobbin URLs you drew from.

## The house palette (in the template)

Warm: ink `#211d17`, rust `#9a3b2e` (accent / how-to / stage numbers), green `#2f5d3a` (carry bands,
"rises", positive), cream `#faf7f1` and sand fills, faint `#a39c8a` for examples. One accent, soft
background, ink text. Keep it.

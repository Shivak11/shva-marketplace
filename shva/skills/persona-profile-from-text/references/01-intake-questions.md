# 01 - Intake questions and the consent gate (Stage 1)

Never build a profile from a one-line brief. Use AskUserQuestion (at most 4 questions per call, 1 to 2 calls). Offer sensible default options and let Shiva add free text. Only ask what the brief has not already answered.

Learn at minimum:

1. **Which mode.** Mirror mode (the text belongs to a Rehearsal user and the profile is shown back to that same person, to pull the next recording) or voice-harvest mode (the text belongs to a target leader and the profile is read by a sales or content team to understand their voice and concerns). This sets the whole output register, so settle it first.
2. **Whose text it is.** The person being profiled, and whether they are the one who provided the text. This matters for consent: a person profiling themselves is different from a third party handing over someone else's notes.
3. **What source types were provided.** Voice notes, journals, transcripts, posts, document uploads, or a mix. You will reclassify every item by source type in Stage 2, but knowing the rough mix up front tells you whether you have reflective content (rich) or mostly uploads (behavioral signals only, thinner read).
4. **The consent tier (this is a gate, not a question you can skip).** Confirm explicit consent for psychological profiling, which is a higher tier than consent to store plain facts. In mirror mode, confirm the person agrees to be profiled and shown the result. In voice-harvest mode, the text is public, but confirm the use is agreed: profiling this leader's voice for outreach or content.
5. **The intended use of the output.** Self-reflection, a sales or content brief, a one-time read, or something that will be stored and reused. The use shapes both the template and the consent.

If the brief already answers some of these, only ask what is missing.

---

## The consent gate (do not pass without it)

Profiling consent is higher-tier than fact-memory consent (see `00-method.md`). Before any extraction:

- **Mirror mode.** Confirm the person consents to a profile being built from their own recordings and shown back to them. If they have only agreed to have their notes stored for recall, that is fact-memory consent, not profiling consent. Stop and ask.
- **Voice-harvest mode.** The source text is public, so the question is not access but use. Confirm the agreed use (understanding voice and concerns for outreach or content). Do not quietly widen the use.
- **Either mode.** If consent for profiling is unclear, do not build the profile. Offer plain fact-memory instead and ask for explicit profiling consent before going further.

Carry the agreed use forward. In "After shipping", any new use beyond what was agreed here needs fresh consent for that specific use.

---

## A note on default options

When you offer options in AskUserQuestion, make the recommended one first and label it. For mode, default to mirror when the person is profiling themselves, voice-harvest when a third party is reading a public leader. For consent, never pre-tick agreement: the person must actively confirm.
